## Overview

This is the full build for the Advanced Life table Longitudinal Simulation for Predicting Adverse Risks and Key Outcomes. (https://darpws.onrender.com/).
The site is hosted on Render and deployed using gunicorn.

## Directory Structure

```text
DARPWS/
├── darpws/                 # Core code and functions
│   ├── app.py              # Main app file
│   ├── orion.py            # Diabetes prevention model
│   ├── cybertronian.py     # Diabetes complication prevention model
│   ├── prime.py            # Plot and table presentation
├── static/                 # html and css files
├── requirements.txt        # Package dependencies
└── README.md               # Repository documentation
```
